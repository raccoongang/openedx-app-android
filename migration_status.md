# CMP Migration Status

Screens and dialogs of the Android OpenEdX app and their migration status to Compose Multiplatform.

Source: `/Users/paul/StudioProjects/openedx-app-android` (branch: main).

## Navigation-path anchors

Abbreviations used in the **Navigation path** column below:

- **App launch (logged-out)** — cold start, user lands on Logistration.
- **App launch (logged-in)** — cold start, user lands on `Main` (Learn tab selected by default).
- **Main** — the bottom-tab host. Tabs: `Learn`, `Discover`, `Dates` (config-gated), `Downloads` (config-gated), `Profile`.
- **CourseContainer** — inside a course; tabs: `Home`, `Content`, `Dates`, `Discussions`, `Handouts`, `Progress`, `Offline`.
- **Deep link** — app opened via external URL (Branch / push notification / system link).
- Bullet `•` separates alternative paths; `→` separates user-visible steps within one path.
